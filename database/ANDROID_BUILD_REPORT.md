# دليل البناء التلقائي لتطبيق «دلنّي» بنظام GitHub Actions (Android APK)

تم إعداد وتجهيز مسار البناء السحابي التلقائي (CI/CD Pipeline) لتطبيق «دلنّي» العقاري باستخدام **GitHub Actions**، لإنتاج حزمة تثبيت أندرويد تجريبية بصيغة **Debug APK** قابلة للتحميل والتثبيت المباشر على الهواتف الذكية.

---

## 2. نتائج الفحص المخبري داخل البيئة الحالية

- ✅ **فحص TypeScript وأنواع البيانات (`npm run lint` / `tsc --noEmit`)**: نجح بنسبة 100% بدون أي أخطاء برمجية.
- ✅ **بناء كود الواجهة الأمامية (`npm run build`)**: تم إنشاء مجلد `dist` بنجاح خلال 1.89 ثانية.
- ✅ **مزامنة كاباسيتور (`npx cap sync android`)**: تم نسخ الأصول الرقمية والمكتبات بنجاح إلى `android/app/src/main/assets/public`.
- ✅ **صلاحيات Gradle Wrapper**: تم ضبط صلاحية التشغيل التنفيذية (`chmod +x android/gradlew`).
- ℹ️ **بيئة الاستضافة المحلية (AI Studio Container)**: لا تحتوي على حزمة أندرويد SDK أو مترجم Java (`java: not found`)؛ ولذلك يتم تنفيذ بناء حزمة الـ APK السحابية عبر خوادم **GitHub Actions** المزودة مسبقاً بكافة أدوات Android SDK الرسمية.

## 3. مواصفات ملف GitHub Actions Workflow

تم حفظ الملف في المسار المعتمد:
`.github/workflows/android-apk.yml`

### أبرز ميزات الـ Workflow:
1. **طرق التشغيل**:
   - يدويًا في أي وقت عبر زر **"Run workflow"** (`workflow_dispatch`) من تبويب Actions في GitHub.
   - تلقائيًا عند دفع أي تحديث جديد إلى الفرع الرئيسي (`main` أو `master`).
2. **منع التضارب (Concurrency Control)**:
   - يلغي أي بناء سابق قيد التشغيل إذا تم رفع تحديث جديد لنفس الفرع لتوفير دقائق البناء.
3. **تثبيت الاعتماديات الذكي**:
   - استخدام خيار `--legacy-peer-deps` لتفادي أي تعارض في حزم React 19 / Vite.
4. **دعم بيئة العمل وحماية الأسرار**:
   - لا توجد أي أسرار أو مفاتيح خاصة مضمنة في الكود أو ملف الـ Workflow.
   - يتم تمرير متغيرات بيئة Supabase تلقائيًا في حال قام المستخدم بإضافتها في **GitHub Repository Secrets** (`VITE_SUPABASE_URL`, `VITE_SUPABASE_ANON_KEY`).
   - في حال لم يتم إدخال المفاتيح، يستمر التطبيق بالعمل بسلاسة عبر التخزين المحلي أو الإعداد اليدوي من داخل التطبيق دون أي انهيار.
5. **التحقق من ملف الـ APK ورفعه**:
   - خطوة تحقق برمجية تتأكد من وجود الملف الناتج في مسار:
     `android/app/build/outputs/apk/debug/app-debug.apk`
   - رفع الملف كـ **Artifact** باسم `dalani-debug-apk` مع الاحتفاظ به لمدة **30 يوماً**.

## 4. خطوات تشغيل البناء وتحميل الـ APK (خطوة بخطوة)

### الخطوة الأولى: رفع التعديلات إلى مستودع GitHub
من الطرفية في مشروعك المحلي (أو بيئة عملك):
```bash
git add .
git commit -m "feat: configure GitHub Actions workflow for Dalani Android APK"
git push origin main
```

*(اختياري) إذا كنت تريد ربط التطبيق مسبقًا بقاعدة بيانات Supabase الخاصة بك أثناء البناء:*
1. توجه إلى مستودعك في GitHub.
2. ادخل إلى **Settings** > **Secrets and variables** > **Actions**.
3. أضف متغيرين في قسم **Repository secrets**:
   - `VITE_SUPABASE_URL`: رابط مشروع Supabase الخاص بك.
   - `VITE_SUPABASE_ANON_KEY`: المفتاح العام (Anon Public Key).

---

### الخطوة الثانية: تشغيل البناء من GitHub Actions
1. افتح صفحة المستودع على **GitHub**.
2. اضغط على تبويب **Actions** في الشريط العلوي.
3. من القائمة الجانبية اليسرى، اختر سير العمل: **"Build Dalani Android APK"**.
4. اضغط على القائمة المنسدلة **"Run workflow"** في الجهة اليمنى.
5. اختر الفرع (`main` أو `master`) ثم اضغط على زر **"Run workflow"** الأخضر.
6. سيبدأ البناء تلقائيًا ويستغرق عادةً ما بين 3 إلى 6 دقائق.

---

### الخطوة الثالثة: تنزيل ملف الـ APK
1. بعد اكتمال البناء وظهور علامة الصح الخضراء (Green Checkmark)، اضغط على اسم البناء (Run).
2. انزل إلى أسفل الصفحة حتى تصل إلى قسم **Artifacts**.
3. ستجد ملفًا باسم: **`dalani-debug-apk`**.
4. اضغط عليه لتنزيله كملف مضغوط (`dalani-debug-apk.zip`) على جهاز الكمبيوتر أو مباشرة على هاتفك.
5. فك الضغط عن الملف وستحصل على: `app-debug.apk`.

---

### الخطوة الرابعة: تثبيت الـ APK على هاتف أندرويد
1. انقل ملف `app-debug.apk` إلى هاتفك عبر (USB، Google Drive، WhatsApp، أو Telegram)، أو حمله من متصفح الهاتف مباشرة.
2. افتح الملف على الهاتف واضغط **تثبيت (Install)**.
3. إذا ظهرت رسالة نظام أندرويد: *"تم حظر التثبيت من مصادر غير معروفة"* أو *"Install unknown apps"*:
   - اضغط على **الإعدادات (Settings)** في الرسالة.
   - فعّل خيار **"السماح من هذا المصدر" (Allow from this source)**.
4. إذا ظهر فحص Google Play Protect:
   - اضغط على **"مزيد من التفاصيل" (More details)** ثم اختر **"التثبيت على أي حال" (Install anyway)** (وهذا طبيعي لجميع حزم الـ Debug التي لم تُوقع بشهادة متجر الإنتاج).
5. افتح تطبيق **«دلنّي» (DLNE)** وابدأ بتجربة كافة وظائف المنظومة العقارية!
