# الفهرس الشامل والأدلة المرجعية لنظام «دلنّي» العقاري (DALANI)
## دليل التوثيق والتحليل الوظيفي والتشغيلي المتكامل

---

### بطاقة النظام الفنية
* **اسم النظام:** منصة «دلنّي» العقارية الوطنية الذكية (DALANI Real Estate Ecosystem).
* **النطاق الجغرافي والتشغيلي:** الجمهورية اليمنية (صنعاء، عدن، تعز، حضرموت، إب، الحديدة، مأرب، ذمار وباقي المحافظات).
* **الإصدار البرمجي الموثق:** v2.4 Enterprise Production Build.
* **البيئة التقنية الأساسية:** React 18 + TypeScript + Vite + Tailwind CSS + Supabase (PostgreSQL / RLS) + Google Maps SDK + Web Print API & Native Android PrintManager Bridge.
* **تاريخ إجراء التحليل والتوثيق:** مارس 2026.
* **صفة المحلل والمهندس:** Senior System Analyst, Software Architect & UX Specialist.

### دليل القراءة والتوجيه السريع بحسب تخصص القارئ
1. **للمطورين الجدد (Software Engineers):**
   * ابدأ بـ `01-SYSTEM-OVERVIEW.md` لفهم المعمارية العامة وموقع الخدمات.
   * انتقل إلى `08-DATABASE-MAPPING.md` لمعرفة كيفية اتصال التطبيق بـ Supabase وآلية المزامنة.
   * راجع `04-BUTTONS-AND-ACTIONS.md` و `09-COMPONENT-RELATIONSHIPS.md` لمعرفة مسار الأحداث وتوزيع المسؤوليات.
2. **لمحللي النظم ومسؤولي الجودة (QA Engineers):**
   * راجع `06-WORKFLOWS.md` و `13-ENTITY-STATUS-FLOWS.md` لفهم آلات الحالة والشروط الحاكمة لكل مرحلة.
   * اعتمد على `14-TEST-PLAN.md` لتنفيذ سيناريوهات الاختبار اليدوي والآلي.
   * راجع `10-EMPTY-AND-INCOMPLETE-STATES.md` للتأكد من سلوك النظام في غياب البيانات أو عند انقطاع الاتصال.
3. **لمسؤولي أمن المعلومات والامتثال (Security & Compliance):**
   * دقق في `12-SECURITY-AND-PERMISSIONS.md` لفحص سياسات RLS، التحقق الثنائي (2FA)، وصمام قفل الحجز المزدوج.
   * افحص `07-ADMIN-DASHBOARD.md` وتحديداً تبويبات سجل التدقيق (Audit Logs) ومراقبة التهديدات (Threat Monitor).
4. **لإدارة المنتج وفريق العمليات والمالية (Product Managers & Operations):**
   * راجع `02-USER-ROLES.md` للتعرف على صلاحيات الكادر التشغيلي وإدارات المكاتب العقارية.
   * راجع `03-ALL-SCREENS.md` للوقوف على تجربة المستخدم الشاملة وتوحيد مسارات المستأجر/المشتري والمعلن.
   * تفحص `15-ISSUES-AND-RECOMMENDATIONS.md` لاعتماد خارطة الطريق التطويرية القادمة.
